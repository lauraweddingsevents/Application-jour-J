# Ma Coordo — Guide pour les prestataires et les proches

*(Texte à copier dans un e-mail ou un message, en accompagnement du lien.)*

---

Bonjour,

Pour que le jour J se déroule au mieux, vous recevez un **lien personnel**
vers le déroulé du mariage. Pas de compte à créer, pas d'application à
télécharger : il suffit de l'ouvrir sur votre téléphone.

**Vous y trouverez :**
- le moment en cours et **votre prochaine mission** (heure, lieu, consignes) ;
- **vos moments** de la journée, et tout le déroulé si besoin ;
- les **infos pratiques** : contacts, adresses avec itinéraire, plan B météo.

**Les horaires changent ?** Votre page se met à jour toute seule, en temps réel.
Un bandeau vous prévient.

**À faire une fois, avant le jour J (2 minutes) :**
1. **Ouvrez votre lien avec du réseau**, idéalement la veille : il restera
   ensuite disponible même dans un lieu qui capte mal.
2. **Ajoutez-le à l'écran d'accueil** :
   - iPhone : dans Safari, bouton Partager ⬆️ → « Sur l'écran d'accueil ».
   - Android : dans Chrome, menu ⋮ → « Ajouter à l'écran d'accueil ».
3. **Activez les alertes** dans le bloc 🔔 (choisissez 5 à 60 minutes avant
   vos moments), puis touchez « Recevoir une alerte de test ».
   Sur iPhone, ouvrez d'abord le lien depuis l'icône « Jour J » de votre écran
   d'accueil.

Ce lien vous est personnel : merci de ne pas le transférer. Si quelqu'un vous
accompagne, prévenez-nous, il recevra le sien.

Une question ? Aide détaillée : https://ma-coordo.vercel.app/aide

À très vite,
Laura — Laura Weddings & Events
